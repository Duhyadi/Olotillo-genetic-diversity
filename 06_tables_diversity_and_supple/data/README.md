# Genetic diversity data tables

This folder contains data tables used to summarize individual- and accession-level genetic diversity metrics for the Olotillo genetic diversity project.

The files include the direct output from `VCFtools` for individual-level homozygosity and inbreeding estimates, as well as a summarized table of diversity metrics by accession.

## Folder contents

```text
data/
├── README.md
├── mixII.het
└── tableS3
```

## File descriptions

| File        | Description                                                                                                                      |
| ----------- | -------------------------------------------------------------------------------------------------------------------------------- |
| `mixII.het` | Individual-level homozygosity and inbreeding estimates generated with `VCFtools` using the `--het` option.                       |
| `tableS3`   | Accession-level summary table of genetic diversity metrics, including means, standard deviations, and sample size per accession. |

## `mixII.het`

The file `mixII.het` is the direct output generated by `VCFtools` using the `--het` option. It contains individual-level estimates of observed homozygosity, expected homozygosity, the number of analyzed sites, and the inbreeding coefficient.

This file was generated using the following command:

```bash
vcftools --gzvcf $mixplates --het --out $out/${project}
```

For this project, the output prefix was `mixII`, producing the file:

```text
mixII.het
```

### Variables in `mixII.het`

| Variable  | Description                                                                          |
| --------- | ------------------------------------------------------------------------------------ |
| `INDV`    | Individual identifier.                                                               |
| `O(HOM)`  | Observed number of homozygous sites for each individual.                             |
| `E(HOM)`  | Expected number of homozygous sites for each individual.                             |
| `N_SITES` | Number of sites included in the individual-level diversity calculation.              |
| `F`       | Individual inbreeding coefficient estimated from observed and expected homozygosity. |

## `tableS3`

The file `tableS3` contains accession-level summaries of genetic diversity metrics derived from individual-level estimates.

Each row corresponds to one accession. The table summarizes the mean and standard deviation of the inbreeding coefficient, observed heterozygosity, expected heterozygosity, and expected homozygosity. It also reports the number of individuals included for each accession.

### Variables in `tableS3`

| Variable       | Description                                                             |
| -------------- | ----------------------------------------------------------------------- |
| `accession_ID` | Accession identifier.                                                   |
| `F_mean`       | Mean inbreeding coefficient across individuals within each accession.   |
| `F_sd`         | Standard deviation of the inbreeding coefficient within each accession. |
| `HETob_mean`   | Mean observed heterozygosity within each accession.                     |
| `HETob_sd`     | Standard deviation of observed heterozygosity within each accession.    |
| `HETex_mean`   | Mean expected heterozygosity within each accession.                     |
| `HETex_sd`     | Standard deviation of expected heterozygosity within each accession.    |
| `HOMex_mean`   | Mean expected homozygosity within each accession.                       |
| `HOMex_sd`     | Standard deviation of expected homozygosity within each accession.      |
| `n`            | Number of individuals included for each accession.                      |

## Relationship between files

The `mixII.het` file contains individual-level estimates generated directly from SNP genotype data. The `tableS3` file summarizes those individual-level metrics by accession.

In general:

```text
mixII.het = individual-level VCFtools output
```

```text
tableS3 = accession-level summary of diversity metrics
```

## Suggested use

These files can be used to:

* report individual-level homozygosity and inbreeding estimates;
* summarize genetic diversity by accession;
* compare diversity metrics among accessions;
* prepare supplementary tables;
* reproduce downstream analyses of heterozygosity, homozygosity, and inbreeding;
* document the genetic diversity estimates used in the Olotillo genetic diversity project.

## Notes

* `mixII.het` is a direct output from `VCFtools`.
* `tableS3` is a summarized table derived from individual-level diversity estimates.
* Missing values represented as `NA` may occur in standard deviation columns when only one individual is available for an accession.
* The file `tableS3` does not include a file extension. If needed for downstream analyses, it can be read as a comma-separated table.
* When reusing these files, keep the original file names to preserve consistency with scripts and supplementary materials.
